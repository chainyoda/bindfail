How it works

01

Design binders

Use RFdiffusion, BindCraft, ESMFold, or any method to generate protein sequences that bind each of the 8 targets.

02

Format as FASTA

One sequence per target, using the target ID as the header. Sequences must be 50–200 residues.

03

Submit via CLI

Run bindfail submit. The server scores each sequence with AF2-Multimer.

04

Score & rank

Score = mean ipTM across all 8 targets. 0.70 = successful binder. Beat the leaderboard to get promoted.

Participate

1

Install the CLI

$ pip install bindfail
2

Get an API key

Click Get API key in the header, or run bindfail login from the CLI.

$ bindfail login
Server: https://bindfail.vercel.app
Register or log in? [register/login]: register
Your name / team: my-team
API key: bf_a1b2c3d4...
3

Submit your designs

One FASTA entry per target ID. Missing targets score 0 ipTM.

# sequences.fasta
>spike_rbd
MKTAYIAKQRQISFVKSHFSRQLEERLGLIEVQAPLAPGMIREDYLDAEYEVK
>pd1
ACDEFGHIKLMNPQRSTVWYACDEFGHIKLMNPQRSTVWYACDEFGHIKLMN
# ...one entry per target
