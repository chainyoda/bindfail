How it works
01

Design binders

Use RFdiffusion, BindCraft, ESMFold, or any method to generate protein sequences that bind each of the 8 targets.

02

Format as FASTA

One sequence per target, using the target ID as the header. Sequences must be 50–200 residues.

03

Submit via CLI

Run bindfail submit. The server scores each sequence with AF2-Multimer ipTM.

04

Score & rank

Score = mean ipTM across all 8 targets. Beat the leaderboard and get promoted. Threshold 0.70 marks a successful binder.

1

Install the CLI

$ pip install bindfail
2

Get an API key

Click Get API key in the top-right, or register from the CLI.

$ bindfail login

3

Design binders and submit

Create a FASTA file with one sequence per target ID, then submit.

# sequences.fasta — one entry per target ID
>spike_rbd
