How it works

01

Design binders

Use RFdiffusion, BindCraft, ESMFold, or any method to design protein sequences that bind each of the 8 targets.

02

Format as FASTA

Put one sequence per target in a FASTA file, with the target ID as the header. Length: 50–200 residues.

03

Submit via CLI

Run bindfail submit sequences.fasta. The server verifies each sequence with AF2-Multimer.

04

Score & rank

Score = mean ipTM across all 8 targets. Threshold 0.70 marks a "successful" binder. Beat the leaderboard.
